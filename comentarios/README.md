# Comentarios del editor

Aquí van las opiniones de Raúl sobre las noticias destacadas. Cada archivo convierte una noticia en
**revisada**: aparece el sello «Revisado», tu opinión firmada y la noticia sube en «Lo más importante de la semana».

## Cómo añadir una

1. Abre la noticia en la web y copia el código de 8 caracteres del final de su dirección.
   Ejemplo: en `.../noticias/la-creatina-puede-ayudar-a-ganar-musculo-3f2a9c1b.html` el código es `3f2a9c1b`.
   (El aviso semanal de «Destacados para revisar» ya te da los códigos.)
2. En GitHub: **Add file → Create new file** dentro de esta carpeta y llámalo `3f2a9c1b.md`.
3. Escribe tu opinión en texto normal (2-5 frases). Puedes usar **negrita** y listas.
4. Pulsa **Commit changes**. En unos minutos estará publicada.

Antes de firmar, lee la noticia original y corrige la ficha si la IA se ha equivocado
(por ahora, avisa a Claude y lo ajustamos).
